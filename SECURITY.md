# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.0 | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly by opening a GitHub issue or contacting the project maintainer.

Please include:

- Description of the issue
- Steps to reproduce
- Expected behavior
- Possible impact

Security reports will be reviewed and addressed as soon as possible.
