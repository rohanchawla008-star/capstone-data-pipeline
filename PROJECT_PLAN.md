# Titanic Data Pipeline Capstone Project

## Project Objective
Build a data pipeline to load, clean, analyze, and visualize the Titanic dataset.

## Scope
- Load Titanic dataset
- Clean missing values
- Perform Exploratory Data Analysis (EDA)
- Build a Machine Learning model to predict passenger survival
- Evaluate model performance

## Milestones

### Week 1
- Project setup
- Data loading
- Data cleaning
- Basic EDA

### Week 2
- Data visualization
- Feature engineering

### Week 3
- Model building

### Week 4
- Model evaluation and final documentation

## Potential Risks
- Missing values in the dataset
- Incorrect preprocessing
- Model overfitting

## Mitigation Strategy
- Proper data cleaning
- Validate preprocessing steps
- Evaluate model using suitable metrics
