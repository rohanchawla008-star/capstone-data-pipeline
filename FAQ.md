# Frequently Asked Questions

## What does this project do?

It predicts whether a Titanic passenger would survive based on passenger details.

## Which machine learning library is used?

Scikit-learn.

## How do I run the project?

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Where is the model stored?

The trained model is stored in the `models/` directory.

## Is the project deployed?

Yes. It is deployed using Streamlit Cloud.
