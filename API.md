# API Documentation

## Prediction Endpoint

The Streamlit application accepts passenger information through an interactive interface and generates predictions using the trained machine learning model.

## Input Features

- Passenger Class
- Sex
- Age
- Fare
- Siblings/Spouses
- Parents/Children
- Embarked Port

## Output

- Survival Prediction
- Survival Probability

No external REST API is currently implemented. Predictions are generated locally within the Streamlit application.
