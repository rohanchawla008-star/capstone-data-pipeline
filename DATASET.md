# Dataset Information

## Overview

This project uses the Titanic dataset, one of the most widely used datasets for binary classification problems in Machine Learning.

## Source

- Kaggle Titanic Dataset
- https://www.kaggle.com/competitions/titanic

## Features

- Passenger Class (Pclass)
- Sex
- Age
- Siblings/Spouses Aboard (SibSp)
- Parents/Children Aboard (Parch)
- Fare
- Embarked Port

## Target Variable

- Survived
  - 0 = Did Not Survive
  - 1 = Survived

## Data Preprocessing

The dataset was preprocessed by:

- Handling missing values
- Encoding categorical variables
- Feature selection
- Data validation
- Preparing inputs for model prediction
