# Project Overview

Titanic Survival Prediction is an end-to-end Machine Learning project that predicts passenger survival using demographic and travel-related features.

The project demonstrates the complete machine learning workflow:

- Data preprocessing
- Feature engineering
- Model training
- Model evaluation
- Model serialization
- Interactive Streamlit deployment
- Version control with Git and GitHub

This project was developed as part of the CodeZoner Capstone Internship Program.
